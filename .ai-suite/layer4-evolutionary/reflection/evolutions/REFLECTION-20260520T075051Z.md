## Task Summary

The user performed two local ai-suite reinstalls and asked the AI to verify the installation
each time. During the first verification pass the AI hardcoded directory names
(`.cursor-suite`, then `.ai-suite`) in `find` searches and failed to locate the meta
framework; the user had to manually state that the directory was renamed and the AI still
required listing `~/` to finally discover `~/.ai-suite-deploy`.

## Improvement Target

- **File:** `.ai-suite/layer4-evolutionary/merging/remote-suite.md`
- **Tier:** core

## Root Cause

- **Category:** Instruction Completeness
- **Severity:** High
- **Description:** The `remote-suite` skill had no documented local deployment path and no
  local-status operation. When the user asked "please verify" without a remote host, no skill
  fired and the AI improvised using `find` with guessed directory names. The canonical path
  `~/.ai-suite-deploy/` was unknown to the AI, causing three rounds of failed searches and
  requiring the user to provide a hint. Adding an explicit Local Status section with the
  canonical path and a "list `~/` first" discovery rule eliminates this guesswork entirely.

## Change Description

Three additions to `.ai-suite/layer4-evolutionary/merging/remote-suite.md`:

1. **New "Local Deployment Path" section** (above Operations): documents the canonical
   `~/.ai-suite-deploy/` root, a path table for all sub-directories, and a hard rule:
   *"When asked to verify a local installation, ALWAYS run `ls -la ~/` first. Never use
   `find` with a hardcoded directory name as the first step."*

2. **New Operation 0 -- Local Status**: a copy-paste bash block (`DEPLOY`, `ls`, `find`)
   that verifies deploy root, scripts, meta, source skills, and deployed skills in one run;
   triggered when intent is verify/status and no `USER@HOST` is present.

3. **Updated Intent Recognition + Host extraction**: "please verify", "reinstalled",
   "confirm install" -> local-status (no-host path); Host extraction rule now routes
   no-host verify intent to Operation 0 without asking for a host.

Triggers added: `verify ai-suite`, `verify the install`, `is ai-suite installed`,
`reinstalled` (4 new, replacing 4 redundant originals to stay within the 20-line
frontmatter limit).
