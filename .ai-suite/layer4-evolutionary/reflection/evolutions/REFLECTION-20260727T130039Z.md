## Task Summary
The human typed "run reflection" while inside the 'Other' input box of the post-task Interactive Workflow `AskQuestion` loop. The AI executed the reflection analysis, but because the Interactive Workflow rule mandated looping back to `AskQuestion` at the end of the input processing, the AI was forced into a state where it technically asked a question *in response* to "run reflection", rather than just breaking out and running reflection directly. This caused confusion and violated the Reflection Protocol's strict "pause all non-reflection work" constraint.

## Improvement Target
- **File:** `.ai-suite/layer1-abstraction/agents/cursor/rules/interactive-workflow.md`
- **Tier:** agents/cursor

## Root Cause
- **Category:** Instruction Completeness
- **Severity:** High
- **Description:** There was a direct rule collision. The `interactive-workflow.md` rule did not contain an exception for handling triggers that dictate a strict one-turn break, such as the Reflection Protocol (`reflection-protocol.md`), which requires the agent to drop everything and immediately execute a specific summary block without additional UI interactions.

## Change Description
Edited `.ai-suite/layer1-abstraction/agents/cursor/rules/interactive-workflow.md` under section 4 (Handling the Interactive Workflow Response). Added a new explicit instruction: `**EXCEPTION for Reflection Protocol:** If the custom text input is a trigger for the Reflection Protocol... you MUST immediately break the interactive workflow loop. Do not execute the task within the interactive loop constraints and do NOT loop back to call AskQuestion. Instead, instantly pause all non-reflection work and execute the strict one-turn Reflection Protocol.`
