# Evolution Report: local-suite-collect

**Host:** local
**Timestamp (UTC):** 20260604T065500Z
**Local suite:** .ai-suite

## Task Summary
The human requested to collect local evolutions from their global Cursor installation (`~/.cursor/skills/`) back into the `.ai-suite` git repository. Because there was no automated command available in `local-suite.md` or `evolve-collect.md`, the AI had to manually write and debug custom bash `for` loops across multiple turns to perform the file diffing and copying.

## Improvement Target
- **File:** `.ai-suite/layer3-registry/core/local-suite.md`
- **Tier:** core

## Root Cause
- **Category:** Instruction Completeness
- **Severity:** High
- **Description:** The `local-suite.md` skill, which governs local lifecycle management, completely lacked instructions on how to "collect" or "sync" evolutions from a local IDE back into the `.ai-suite` directory structure. Because local skills are flattened into `~/.cursor/skills/` while `.ai-suite/` is tiered, simply running `cp` or `evolve_suite.sh collect` does not work, stranding local evolutions unless manually scripted.

## Change Description
Appended a new `3. Collect (sync local evolutions back to repo)` section to the `local-suite.md` skill. It provides the AI with a pre-written, highly robust bash snippet that iterates through `~/.cursor/skills/`, dynamically maps them to their nested `.ai-suite/` source paths using `find`, diffs them, and syncs both the markdown files and any associated python/bash scripts directly back into the codebase. It also adds new trigger keywords for local collection.
