## Task Summary
The human requested to improve the evolution capability of the AI suite by making it strictly based on the LLM's semantic understanding. The goal was to ensure that evolutions demonstrably improve the AI suite Agent's effectiveness (understanding and processing of prompts, skills, rules) and make the suite easier to use for the end user.

## Improvement Target
- **File:** `.ai-suite/layer4-evolutionary/reflection/reflection-protocol.md` and `.ai-suite/layer4-evolutionary/merging/evolve-collect.md`
- **Tier:** meta and core

## Root Cause
- **Category:** Instruction Completeness
- **Severity:** High
- **Description:** The previous evolution protocols and collection skills lacked explicit constraints mandating that evolutions must be driven by deep semantic understanding. Without these constraints, evolutions could regress to superficial syntactic or file-level matching, failing to improve agent effectiveness or end-user usability.

## Change Description
Added a new `CORE EVOLUTION PRINCIPLES` section to both `.ai-suite/layer4-evolutionary/reflection/reflection-protocol.md` and `.ai-suite/layer4-evolutionary/merging/evolve-collect.md`. This section explicitly mandates that all evolutions must adhere to three semantic principles: Semantic Understanding, Agent Effectiveness, and End-User Usability. Also created a suite of BDD scenarios and contract tests to enforce these principles architecturally.
