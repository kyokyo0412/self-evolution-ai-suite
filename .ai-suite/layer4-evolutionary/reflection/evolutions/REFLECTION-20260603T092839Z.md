## Task Summary
The human was running a TDD-based robustness improvement task and asked the AI to "run reflection." The AI incorrectly interpreted this as a trigger to execute Phase 5 (Documentation & Project Closure) of the `tdd-team` process, instead of engaging the suite-wide Reflection Protocol.

## Improvement Target
- **File:** `core/process/tdd-team.md`
- **Tier:** core

## Root Cause
- **Category:** Trigger Accuracy
- **Severity:** High
- **Description:** The `tdd-team` skill lacked a negative constraint preventing it from hijacking the "run reflection" trigger. Because "reflection" sounds conceptually similar to project closure/review, the AI naturally mapped the phrase to Phase 5 of the TDD process rather than correctly identifying it as the trigger for the `.ai-suite/layer4-evolutionary/reflection/reflection-protocol.md`.

## Change Description
Added an explicit negative constraint to the `tdd-team.md` skill to strictly forbid the AI from treating "run reflection" as a Phase 5 trigger. The constraint explicitly instructs the AI to stop the TDD process and execute the Reflection Protocol instead.

- Q1 (all agents): YES

- Q3 (agent-specific): NO
- Q4 (domain-specific): NO
- **Tier chosen:** core
- **Justification:** The `tdd-team` process is a core process applicable to all agents and domains, so the fix must reside in the core tier.
