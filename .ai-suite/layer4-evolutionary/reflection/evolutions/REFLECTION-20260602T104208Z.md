## Task Summary
The human requested to enable the ai-suite locally and globally, followed by a remote installation.

## Improvement Target
- **File:** `.ai-suite/layer3-registry/core/local-suite.md`
- **Tier:** core

## Root Cause
- **Category:** Trigger Accuracy / Instruction Completeness
- **Severity:** High
- **Description:** While there was a skill (`remote-suite.md`) to handle remote ai-suite lifecycle management, there was no equivalent skill for local operations. Consequently, the agent had to manually search for and read the `ai-suite enable` script to understand how to fulfill the request. This resulted in unnecessary friction and less optimal output (failing to mention disable instructions).

## Change Description
Created `.ai-suite/layer3-registry/core/local-suite.md` to define a dedicated skill for local ai-suite lifecycle management (install/enable and remove/disable), mirroring the user experience of `remote-suite.md` but specialized for local paths.

- **Tier chosen:** core
- **Justification:** The core local installation mechanism applies uniformly to all AI agents.
