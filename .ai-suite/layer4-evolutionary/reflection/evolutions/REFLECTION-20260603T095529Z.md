## Task Summary
The human was trying to separate domain-specific skills from the core `ai-suite` directory into a new `domains/vmware/skills/` directory. During this process, the AI created new skills but failed the `validate-suite.sh` check because it omitted the mandatory `"Use when"` phrase in the skill descriptions.

## Improvement Target
- **File:** `.ai-suite/layer1-abstraction/agents/cursor/skills/ai-suite-architect.md`
- **Tier:** agents/cursor

## Root Cause
- **Category:** Instruction Completeness
- **Severity:** High
- **Description:** The `ai-suite-architect` skill, which is responsible for designing and creating `ai-suite` skills, did not explicitly instruct the AI to follow the strict frontmatter validation rules enforced by `validate-suite.sh`. As a result, the AI frequently forgot to include the `"Use when"` phrase in the description, causing validation pipelines to fail and requiring manual pivots.

## Change Description
Added a new rule `Skill Frontmatter Strictness` to the `Rules of Engagement` section in `ai-suite-architect.md`. This rule explicitly mandates that new `.ai-suite` skills must include valid YAML frontmatter, the `name:` must match the filename, the `description:` MUST contain the exact phrase `"Use when"`, the frontmatter must close within the first 20 lines, and the body must be <= 600 lines.
