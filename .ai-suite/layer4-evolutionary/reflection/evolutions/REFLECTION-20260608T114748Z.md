## Task Summary
The human requested to run reflection. In a previous task, the user asked to enable the ai-suite globally for all projects on a remote `dbc` server. The `remote-suite.md` skill failed to parse the phrase "for all projects" because it was only looking for the exact phrase "global".

## Improvement Target
- **File:** `.ai-suite/layer4-evolutionary/merging/remote-suite.md`
- **Tier:** core

## Root Cause
- **Category:** Trigger Accuracy
- **Severity:** Medium
- **Description:** The `remote-suite.md` skill had a very rigid table for mapping user phrases to CLI flags. It only mapped `"global" (default)` to `--remote-scope global`. When the user said "for global (all projects)", the AI failed to map this correctly and instead used the default project scope, or got confused.

## Change Description
Updated the Intent Recognition / Options extraction table in `remote-suite.md`. Expanded the mapping for the global scope to include common natural language variations: `"global" (default), "for global", "all projects"`.
