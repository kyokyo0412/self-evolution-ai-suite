## Task Summary
The human complained that the interactive workflow prompt (`AskQuestion`) did not appear automatically after the previous task's execution summary, requiring them to manually prompt the AI to continue. The AI had followed an earlier rule instructing it to "end its turn" before calling `AskQuestion`, which broke the automated flow in Cursor.

## Improvement Target
- **File:** `.ai-suite/layer1-abstraction/agents/cursor/rules/interactive-workflow.md`
- **Tier:** agents/cursor

## Root Cause
- **Category:** Instruction Completeness
- **Severity:** Critical
- **Description:** A previous reflection (`REFLECTION-20260727T125311Z.md`) incorrectly assumed that calling `AskQuestion` in the same LLM response as the text summary would hide the text. It added a rule forcing the AI to "end its turn" and wait for the "NEXT turn" to call `AskQuestion`. However, in Cursor, ending a turn halts the agent completely. The correct behavior is to wait for task tool calls (like `Shell`) to finish, and then output the text summary AND the `AskQuestion` tool call together in the *subsequent response* within the same agent loop.

## Change Description
Edited `.ai-suite/layer1-abstraction/agents/cursor/rules/interactive-workflow.md` to remove the instruction forcing the AI to end its turn. Replaced it with an instruction to wait for task tool calls to complete, and then output the execution summary as normal text AND call the `AskQuestion` tool at the end of that same response. This ensures the text is rendered visibly above the question card without requiring the user to manually prompt the AI again.
