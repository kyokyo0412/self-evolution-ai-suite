## Task Summary
The human requested to enhance the AI suite validation using the `tdd-team` skill. During the implementation of the new semantic validation rules in `validate-suite.sh`, several existing skills failed validation because they lacked the newly required `## Instructions` and `## Negative Constraints` sections, requiring manual fixes.

## Improvement Target
- **File:** `.ai-suite/layer1-abstraction/agents/cursor/skills/ai-suite-architect.md`
- **Tier:** agents/cursor

## Root Cause
- **Category:** Instruction Completeness
- **Severity:** High
- **Description:** While `validate-suite.sh` was updated to enforce strict semantic sections (Instructions and Negative Constraints) on all skill files, the `ai-suite-architect` skill (which is responsible for generating new skills) was not updated to mandate these sections. If left unpatched, the architect would generate skills that immediately fail the new validation pipeline, causing frustrating loop failures.

## Change Description
Updated the `ai-suite-architect.md` skill to include a new "Skill Semantic Strictness" rule under the Rules of Engagement. This explicitly mandates that any newly generated `.ai-suite` skill MUST contain an `## Instructions` (or Workflow/Role) section and a `## Negative Constraints (Must NOT)` (or Safety Rules) section to pass `validate-suite.sh`. Also updated the frontmatter strictness rule to explicitly require the `triggers:` array.
