## Task Summary
The human pointed out that temporary files (`.bak` and `patch_*.sh`) were left in the workspace and questioned why the interactive-workflow was not invoked seamlessly. The root of the workspace pollution issue was that the AI agent used intermediate files to modify configurations but didn't have a strict directive to clean them up afterward.

## Improvement Target
- **File:** `.ai-suite/layer3-registry/directives/agent-directives.md`
- **Tier:** core

## Root Cause
- **Category:** Instruction Completeness
- **Severity:** High
- **Description:** The agent's core directives lacked a strict cleanup policy. Without this, operations that securely manipulate files via shell scripts (like using `sed -i.bak` or writing temporary patch scripts) leak artifacts into the user's workspace, leading to friction and complaints.

## Change Description
Appended a new "8. Workspace Cleanup" section to the General Agent Directives. This mandates that the AI agent must actively clean up any `.bak`, `.tmp`, or execution script artifacts generated during its operations before considering a task complete.

## Generality Gate Result
- Q1 (all agents): YES
- Q2 (agent-specific): YES
- Q3 (domain-specific): NO
- **Tier chosen:** core
- **Justification:** Workspace cleanliness is a universal requirement for all AI agents acting autonomously on any project.
