## Task Summary
The human requested to deploy the AI suite locally and globally to multiple remote hosts. I performed the task and executed the newly tightened `AskQuestion` interactive workflow. However, after the task completed, I hid the text summary and the final `AskQuestion` prompt in the same LLM tool-call turn, depriving the user of seeing the summary before having to interact with the prompt.

## Improvement Target
- **File:** `.ai-suite/layer1-abstraction/agents/cursor/rules/interactive-workflow.md`
- **Tier:** agents/cursor

## Root Cause
- **Category:** Output Quality
- **Severity:** High
- **Description:** The rule stated the agent must output text *before* calling `AskQuestion`, but because AI agents aggressively batch independent tool calls (like string outputs and AskQuestion triggers) in the same turn for latency optimization, this instruction was bypassed. A stricter architectural directive was required to explicitly forbid tool-call bundling at the end of the run.

## Change Description
Edited `.ai-suite/layer1-abstraction/agents/cursor/rules/interactive-workflow.md` to introduce a "CRITICAL HARD BLOCK FOR FINAL OUTPUT". 
It explicitly instructs the agent that it MUST NOT call the final `AskQuestion` tool in the same turn where it executes the final summary output. The agent must yield the turn to the user first. 
Also added a specific Negative Constraint: `[X] Do NOT bundle the final text summary and the final AskQuestion in the same tool call batch if there are pending actions. You must yield the text output to the user first.`

## Generality Gate Result

- Q2 (agent-specific): NO
- Q3 (domain-specific): YES (Cursor-specific)
- **Tier chosen:** agents/cursor
- **Justification:** The `AskQuestion` tool and this interactive rule are completely specific to the Cursor IDE execution environment.
