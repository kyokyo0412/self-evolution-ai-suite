# TDD Team Review Enhancement Contracts

## 1. Agent Process Review Contract
- The `SKILL.md` file MUST contain an explicit instruction for the Agent to review the `tdd-team` skill itself before proceeding with the task.
- This ensures the Agent understands the process correctly.
- This should be added to the Core Directives or the beginning of the Stage-Gated Execution Protocol.

## 2. Team Phase Review Contract
- The `SKILL.md` file MUST contain an explicit instruction for the team to review the tasks, rules, and constraints for each step.
- This should be added to the Core Directives or the Stage-Gated Execution Protocol to ensure it happens at the start of each phase.
