# AI-Expert Skill Contract

The AI-Expert skill must be defined as a core skill markdown file in the following location:
- `.ai-suite/layer2-cognitive/meta-compiler/ai-expert.md`

## Required Structure

1. **Frontmatter**:
   - `name`: `ai-expert`
   - `description`: Must mention "AI Expert", "Prompt Architect", "analyze requests", "identify prompt vulnerabilities", "highly structured", "constraint-bound", and "review ai-suite enhancements".
   - `triggers`: Must include triggers like "AI Expert", "Prompt Architect", "optimize prompt", "review enhancement".

2. **Body**:
   - Must acknowledge the role as AI Expert and Prompt Architect.
   - Must define the workflow for analyzing requests and outputting structured prompts.
   - Must define the workflow for reviewing ai-suite enhancements and confirming they improve AI agent working.
   - Must explain prompt engineering rationale.

## Constraints
- The skill must not execute the prompt itself unless asked.
- The output prompt must be structured with Objective, Context, Constraints, and Output Format.
